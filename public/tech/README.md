Names without a usable logo render as text chips and are listed in `TEXT_ONLY_TECH`: generic concepts, research models, libraries that publish no logo, wordmark-only logos (Checkov, Darts, Gensim, XGBoost) and marks without a CC0 or published reuse terms (OpenAI and Codex, Semgrep, Gitleaks, Grype, TruffleHog, Nessus, iPaymu, RajaOngkir, DataTables). Wherever chips show logos, text chips come after every logo chip (`sortLogosFirst`).

The 3D Lobby walls draw these logos from one prebuilt atlas (`public/atlas/`): after adding, removing or replacing a logo the skills or certification wall shows, run `bun run logo:atlas` and commit its output. The B1 Stack Halo has its own atlas (`public/atlas/engine.*.webp`, the build story's `stack` and the agents' `tools`; Codex is drawn as a text cell): after changing either list or one of its logos, run `bun run engine:atlas`.
