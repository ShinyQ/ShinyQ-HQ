# Tech logos

Icons used by `src/content/tech.ts` (`getTechLogo`). Files are named by registry key.

| Source | Files | Terms |
| --- | --- | --- |
| [Simple Icons](https://simpleicons.org) | most `*.svg` brand marks | CC0 1.0 for the icon data; brand marks remain trademarks of their owners. Dark brand colors are lightened for the dark theme. |
| Simple Icons (social) | `github.svg`, `medium.svg`, `google-scholar.svg`, `ieee.svg` | Same CC0 terms; used for contact and research profile links. LinkedIn is absent from Simple Icons, so it stays text. |
| [Azure architecture icons](https://learn.microsoft.com/azure/architecture/icons/) (V24) | `azure*.svg`, `app-service`, `application-insights`, `arm-templates`, `blob-storage`, `container-apps`, `content-safety`, `cosmos-db`, `document-intelligence`, `foundry`, `key-vault`, `log-analytics`, `managed-*`, `service-bus` | Used per Microsoft's icon terms (architecture diagrams, training materials and documentation). |
| [Microsoft Fabric icons](https://learn.microsoft.com/fabric/fundamentals/icons) (`@fabric-msft/svg-icons` 8.4.0, 48 px color/item set) | `fabric.svg`, `fabric-lakehouse.svg`, `fabric-data-pipelines.svg` | Used per Microsoft's Fabric icon terms (architecture diagrams, training materials and documentation); unmodified apart from a `viewBox` and dropping the root `fill="currentColor"`. |
| Microsoft brand mark | `microsoft.svg` | The four-square logo drawn from Microsoft's published brand colors; identifies Microsoft as a certification issuer. |
| Simple Icons (16.35.0) | `vite.svg`, `cloudflare-workers.svg`, `cloudflare-d1.svg` | Same CC0 terms; D1 has no mark of its own, so `cloudflare-d1.svg` is the Cloudflare mark. |
| Simple Icons (issuers) | `hackerrank.svg` | Same CC0 terms; identifies HackerRank as a certification issuer. |
| [microsoft/agent-framework](https://github.com/microsoft/agent-framework) | `agent-framework.webp` | Project artwork from the public repository. |
| Owner's previous portfolio | remaining `*.webp` rasters | Trimmed and padded to 96 x 96. |

Names without a usable logo render as text chips and are listed in `TEXT_ONLY_TECH`.
