About and contact

Through school and Telkom University, I earned 20 competition placings, including seven first places, in work ranging from chatbot prototypes to data science and capture-the-flag. How I work

I define each feature in a written spec with acceptance criteria. GitHub Copilot and Claude Code implement much of the code in parallel; I remain responsible for design, review, verification on Azure and the merge. I use gold sets, A/B tests, CI gates and shadow mode to evaluate changes, and report metrics with their measurement method.

  1. Define the spec first

    I write a numbered spec with acceptance criteria and a constitution that sets the agents' working rules before implementation starts.

  2. Delegate implementation, own the review

    AI coding agents implement much of the code in parallel. I am responsible for design, review, verification on Azure and the merge decision.

  3. Evaluate before release

    I evaluate changes with gold sets, A/B tests, CI gates and shadow mode. I record negative results and leave changes disabled when they do not help.

  4. Design for recovery

    I plan for failures and build a recovery path rather than assume the system will always work.

  5. Report metrics with context

    I publish a metric only when I can explain how it was measured: in the lab, offline or live.
