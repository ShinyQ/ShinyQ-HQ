# Cinematic Landing (Page View Home) Implementation Plan

Status: shipped in #54 (45c608b), 2026-10-12. Later removed in #141: the ticker's "Pause motion" switch and "Updated" stamp

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Page View home (`/{locale}`, e.g. https://kurniadi.pages.dev/en) into a cinematic, welcoming first screen: the owner's name over a lightweight animated Neon Grid backdrop, clear "Enter the 3D HQ" and "Ask AI" calls to action, a live stats ticker and three featured projects with gallery images, with nothing (no Rover Terminal) covering it on first paint, and every performance budget still green.

**Architecture:** Server-rendered hero (`HomeHero`) with a CSS-only backdrop (`src/app/landing.css`, compositor-only transforms, no JavaScript, no image, so it never competes for LCP), a server-rendered `StatTicker` (`#stats`, CSS marquee with a native "Pause motion" checkbox, still under reduced motion), `FeaturedProject` cards chosen by a pure `pickFeaturedPods` helper, and one small client island, `EnterHqButton`, whose visibility is decided before first paint by a new `html[data-hq-3d]` flag from the existing boot-first head script and whose click is handled by `ExperienceGate` through a new `enter3d` HUD command. `MissionHud` stops auto-opening the Rover Terminal on the Page View; the 3D Lobby keeps opening it after the intro (Director, unchanged).

**Tech Stack:** Next.js 16 static export, React 19, TypeScript strict, Tailwind CSS 4, next-intl, zustand (unchanged), Vitest + Testing Library, Playwright + axe, Lighthouse CI, Bun.

## Global Constraints

- Repo: `ShinyQ/ShinyQ-HQ`, branch from up-to-date `main` (reference commit `2f986ab`). Read `AGENTS.md` and `README.md` before starting.
- No em dashes (U+2014) anywhere: code, comments, copy, docs, commits, PR text (a unit test scans the repo). Use commas, colons, parentheses or "to".

- Static export only: no server runtime, no `next/image` optimization. Every route keeps working without WebGL.
- 3D behavior unchanged: the Director still opens the Rover Terminal after the intro on the first 3D visit (`e2e/experience.spec.ts` "the terminal opens after the intro on the first visit" must stay green).
- Terminal rule (decided): the Page View never auto-opens the Rover Terminal (any route, any tier). It opens only from the header button, Cmd-K/missions, or the 3D Lobby after the intro.
- Lighthouse CI budgets (`lighthouserc.json`, median of 3 runs, `/en`, `/en/quick`, `/en/journey`, `/en/labs/voice-ai-contact-center`, default mobile profile): `largest-contentful-paint` <= 2000 ms, `cumulative-layout-shift` <= 0.01, `total-blocking-time` <= 200 ms, `resource-summary:font:size` <= 61440 B, `resource-summary:document:size` <= 81920 B, `resource-summary:stylesheet:size` <= 20480 B, `resource-summary:script:size` <= 245760 B; performance, accessibility and SEO scores >= 0.9 (warn).
- Layouts verified at desktop 1440x900, tablet 834x1112 and mobile 390x844.
- Motion: CSS only (`transform`/`opacity`), starts after a 0.5 s delay, `prefers-reduced-motion: reduce` gives a still frame, and a visible "Pause motion" checkbox stops it (WCAG 2.2.2). The hero `h1` never animates (it is the LCP element).

- Floor and wing colors are wayfinding only (markers, tower slabs, rules); never fill large surfaces with them.
- Fast verification before every push: `bun run verify:quick` then `bun run e2e:changed`. Commit in logical steps with conventional messages through the `rtk` git wrapper (`rtk git add`, `rtk git commit`). One PR; do not merge without the owner.

```ts
import { useSyncExternalStore } from "react";
import { isBotLike, PROBE_KEY } from "@/lib/boot-first";
import { decideTier, readTierInputs } from "@/lib/gpu-tier";
import type { GpuTier } from "./types";

let detected: GpuTier | undefined;
let scheduled = false;
const tierListeners = new Set<() => void>();

/**
 * Probes WebGL once per page load, after the commit that mounts the first subscriber (ExperienceGate
 * or the landing's EnterHqButton). Creating a context is not free (seconds on software renderers such
 * as SwiftShader), so it must never run during render: a client navigation into a gated route would
 * block until the probe finishes.
 */
function subscribeTier(listener: () => void) {
  tierListeners.add(listener);
  if (detected === undefined && !scheduled) {
    scheduled = true;
    window.setTimeout(() => {
      // Crawlers and automation stay on the page: no WebGL probe, no 3D chunk.
      if (detected === undefined && isBotLike(navigator, window.location.search)) detected = "static";
      if (detected === undefined) {
        const inputs = readTierInputs(window.location.search);
        detected = decideTier(inputs);
        // Remember an auto-detected static device, so the next page skips the boot cover.
        if (detected === "static" && !inputs.override) {
          try {
            sessionStorage.setItem(PROBE_KEY, "static");
          } catch {
            // Storage can be unavailable; the cover then shows until the probe, as on this page.
          }
        }
      }
      tierListeners.forEach((l) => l());
    }, 0);
  }
  return () => {
    tierListeners.delete(listener);
  };
}
const readDetectedTier = () => detected ?? null;
const readServerTier = () => null;

/** The GPU tier of this page load: null on the server and until the probe has run after the first commit. */
export function useGateTier(): GpuTier | null {
  return useSyncExternalStore(subscribeTier, readDetectedTier, readServerTier);
}
```

/**

export function pickFeaturedPods<T extends Pick<Pod, "assets">>(sorted: readonly T[], count = 3): T[] {
