# L4 Writing Revamp (Reading Room, Newsroom or Constellation) Implementation Plan

Status: shipped in #56 (1a1400c), 2026-10-12. Later removed in #167: the "Read my writing" walk (the mission stays)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the L4 Library ("Writing" in the HUD) into a walkable floor that is more interesting to explore: three playable concepts for the owner to pick from, then the picked concept shipped on the real floor with roads, plazas, a guided "Read my writing" walk, the existing Glass Drawer and paper preview modal, and unchanged deep links.

**Architecture:** One shared, pure contract (`floors/library/model.ts`: `LibraryLayout`, `dockAlong`, `signsFor`, `paperSlots`, `tagLinks`) that three pure concept builders implement (`concepts/atrium.ts`, `newsroom.ts`, `constellation.ts`), each passing the walkable-floor space rules with the real content. R3F decor per concept (`decor/*.tsx`) takes the same `DecorProps`, so the dev prototype (`/{locale}/dev/library`) and the real floor render identical scenes. After the owner's pick, `layout.ts` (`buildLibraryLayout`) and `Library.tsx` import only the picked builder and decor (the losers stay for the dev prototype only and never reach the 3D chunk), `libraryWalk` builds "Read my writing" from the layout's station order, and the `blog` mission becomes `elevator L4` then `walk writing`.

**Tech Stack:** Next.js 16 (static export), React 19, TypeScript strict, three.js + React Three Fiber + drei (troika text), zustand, next-intl, Vitest, Playwright on SwiftShader, Bun.

## Global Constraints

- No em dashes (U+2014) anywhere: code, comments, copy, docs, commit messages, PR text (`tests/content/safety.test.ts` scans the repo). Use commas, colons, parentheses or "to".
- Public repo: never commit private evidence, client company names, cloud resource names or personal data.
- Content is data: post, paper, model and talk titles come from `content/site-content.json` through `ExperienceData` (`data.library`), never literals in components (another session applies Title Case to titles; nothing here may assume a casing). Zone names come from messages (`library.posts`, `library.research`, `library.publications`, `library.talks`).
- Bilingual: every new UI string goes into both `messages/en.json` and `messages/id.json` with identical keys and placeholders (`tests/unit/ui-copy.test.ts`).
- Static export: the concepts prototype is a `page.dev.tsx` route, so it exists only under `next dev` or `HQ_DEV_PAGES=1` and never in `out/`.
- Every route works without WebGL; `/{locale}/library` and `/{locale}/blog/{slug}` keep their HTML content.
- Render budget: every floor stays under 150 draw calls and 30k triangles (`expectRenderBudget` in `e2e/hq.ts`).
- Walkable floor space rules (`src/experience/nav/space.ts`, asserted with `expectSpaceRules`): roads at least 8 u wide, plazas at least 16 u, 6 u of clear floor around obstacles, every door has a spur ending on its pad and a `facing`.
- The elevator door stays at (-24, 0), the approach at (-21, 0), the slab's west edge at x = -24 (shaft at x = -28).
- Coordination: a parallel session puts an elevator call pad in front of the elevator on every floor. Keep `LIBRARY_FLOOR.padZone` (x -24 to -15, z -4.5 to 4.5) free of obstacles, door pads, stations, signs and the spawn; the lead road may cross it. Other parallel sessions own HUD polish, the RF revamp, the landing page and content: do not touch their files; the only content edit here is `missions[id="blog"].steps` (Task 3). New e2e code goes through the shared helpers (`runMission`, `enterHQ`, `enterFloorRoute`, `openWithWalks`), so the HUD session's renames (for example the Missions button becoming "Ask Rover") and intro changes flow through; when another session merged first, rebase and re-run the touched specs.
- Performance tiers: `full` and `lite` in 3D (lite drops halos and additive glow), `static` shows the HTML page. Reduced motion holds every animation still (page turns, ticker, stars, core).
- Pure modules (`model.ts`, `concepts/*.ts`, `layout.ts`, `decor/flipBooks.ts`, `missions/walks.ts`) import no React, store or three side effects.
- Touch targets at least 44 px (`min-h-11`).
- Screenshots: 1440x900, 834x1112 and 390x844, headless Chromium with `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`, a normal desktop user agent, and waiting for the ready signal before capturing.
- Never write to `/tmp`; screenshots go to `screenshots/` (gitignored).
- Package manager Bun. Conventional commits (`feat:`, `fix:`, `test:`, `docs:`, `chore:`). One PR; do not merge without the owner.

import type { RoomId } from "@/content/schema";
import { ROAD, type RoadNetwork } from "../../nav/road";
import type { ViewZone } from "../../camera/orbit";
import type { FloorLayout, LibraryData, Rect, Vec2 } from "../../types";

/**
 * Shared contract of the L4 Writing floor (walkable floors plan, part 3). Every concept builder
 * (`concepts/*.ts`) returns a `LibraryLayout`, so the floor, the walk, the camera zones and the decor
 * read the same stations whatever concept ships. Pure: no React or three.
 */

export type LibraryConcept = "atrium" | "newsroom" | "constellation";
export const LIBRARY_CONCEPTS: readonly LibraryConcept[] = ["atrium", "newsroom", "constellation"];

/** Category of a station; display names come from messages (`library.posts`, `library.research`, ...). */

export const LIBRARY_FLOOR = {
  door: { x: -24, z: 0 } as Vec2,
  approach: { x: -21, z: 0 } as Vec2,
  slabMinX: -24,
  accent: "#e5e7eb",
  road: ROAD.minWidth,
  margin: 6,
  /** Posts docked on the floor; older ones go to the archive board and the posts palette. */
  maxPosts: 12,
  /**
   * Kept free for the elevator call pad (parallel work: a pad in front of the elevator on every floor):
   * no obstacle, door pad, station or sign may touch it. The lead road may cross it.
   */
  padZone: { minX: -24, maxX: -15, minZ: -4.5, maxZ: 4.5 } as Rect,
} as const;

/** Docking sizes: `along` the road and `across` it (u). */
export const STATION_SIZE: Record<LibraryZone, { along: number; across: number }> = {
  blog: { along: 4, across: 4 },
  research: { along: 10, across: 6 },
  models: { along: 8, across: 6 },
  talks: { along: 8, across: 6 },
};

export const DOCK = {
  /** Clear floor between two stations on the same side of a road (space rules: at least 6 u). */
  gap: 6,
  /** Road edge to station front. */
  forecourt: 3,
  /** Station front to door pad center (the rover fits on the pad). */
  padInset: 1.1,
  spurWidth: 3,
} as const;

export interface LibraryStation {
  room: RoomId;
  zone: LibraryZone;
  rect: Rect;
  center: Vec2;
  /** Door pad center (`DoorTrigger.at`). */
  door: Vec2;
  /** Unit direction from the pad into the station. */
  facing: Vec2;
  /** Spur start on the road centerline. */
  from: Vec2;
}

export interface LibraryLayout {
  concept: LibraryConcept;
  floor: FloorLayout;
  network: RoadNetwork;
  /** Walk order: docked posts (newest first, the featured post first where a concept has one), then research, models, talks. */
  stations: LibraryStation[];
  /** Slugs of posts beyond `maxPosts` (archive board and the posts palette). */
  archive: string[];
  /** Archive board with the stop in front of it (null while every post is docked). */
  board: { rect: Rect; center: Vec2; stop: Vec2 } | null;
  /** Zone sign anchors (floor text and icon) with the direction the zone's road runs. */
  signs: Record<LibraryZone, { at: Vec2; heading: Vec2 }>;
  /** Concept centerpiece (atrium book, press stage screen, star core). */
  centerpiece: Vec2;
  /** Docked posts that share a tag (constellation lines; other concepts may ignore them). */
  links: [RoomId, RoomId][];
  /** Concept extras the decor reads (headline wall, year marks, nebulae). */
  extras: { wall?: Rect; years?: { year: string; at: Vec2 }[]; nebulae?: Record<LibraryZone, Vec2> };
}

export const roomOfPost = (slug: string): RoomId => `L4:${slug}` as RoomId;
export const ZONE_ROOM: Record<Exclude<LibraryZone, "blog">, RoomId> = { research: "L4:research", models: "L4:publications", talks: "L4:talks" };

export interface DockItem {
  room: RoomId;
  zone: LibraryZone;
}

/** Axis-aligned road segment to dock along, from `a` toward `b`. */
export interface DockRun {
  a: Vec2;
  b: Vec2;
  /** +1 or -1: side of the road, along the normal (-u.z, u.x) of the travel direction u. */
  side: 1 | -1;
  /** Distance from `a` to the first station's near edge. */
  start: number;
  roadWidth?: number;
}

/**
 * Docks stations along one side of an axis-aligned road segment, in order, `DOCK.gap` apart, each
 * with a forecourt, a door pad facing the road and a spur from the road centerline. Returns the
 * stations and the distance from `a` past the last station's far edge.
 */
export function dockAlong(items: readonly DockItem[], run: DockRun): { stations: LibraryStation[]; end: number } {
  const len = Math.hypot(run.b.x - run.a.x, run.b.z - run.a.z) || 1;
  const u = { x: (run.b.x - run.a.x) / len, z: (run.b.z - run.a.z) / len };
  // `+ 0` turns -0 into 0, so facings compare equal in tests and logs.
  const n = { x: -u.z * run.side + 0, z: u.x * run.side + 0 };
  const half = (run.roadWidth ?? LIBRARY_FLOOR.road) / 2;
  let cursor = run.start;
  const stations = items.map((item) => {
    const { along, across } = STATION_SIZE[item.zone];
    const s = cursor + along / 2;
    cursor += along + DOCK.gap;
    const from = { x: run.a.x + u.x * s, z: run.a.z + u.z * s };
    const off = half + DOCK.forecourt + across / 2;
    const center = { x: from.x + n.x * off, z: from.z + n.z * off };
    const w = Math.abs(u.x) * along + Math.abs(n.x) * across;
    const d = Math.abs(u.z) * along + Math.abs(n.z) * across;
    const pad = half + DOCK.forecourt - DOCK.padInset;
    return {
      room: item.room,
      zone: item.zone,
      rect: { minX: center.x - w / 2, maxX: center.x + w / 2, minZ: center.z - d / 2, maxZ: center.z + d / 2 },
      center,
      door: { x: from.x + n.x * pad, z: from.z + n.z * pad },
      facing: { x: n.x, z: n.z },
      from,
    };
  });
  return { stations, end: cursor - DOCK.gap };
}

/** Docked posts (capped) and the archive, from the input (newest first). */
export function splitPosts(input: LibraryLayoutInput): { docked: DockItem[]; archive: string[] } {
  const docked = input.posts.slice(0, LIBRARY_FLOOR.maxPosts).map((p) => ({ room: roomOfPost(p.slug), zone: "blog" as const }));
  return { docked, archive: input.posts.slice(LIBRARY_FLOOR.maxPosts).map((p) => p.slug) };
}

/** The non-post stations that have content (an empty shelf gets no station). */
export function shelfItems(input: LibraryLayoutInput): DockItem[] {
  const out: DockItem[] = [];
  if (input.research) out.push({ room: ZONE_ROOM.research, zone: "research" });
  if (input.models) out.push({ room: ZONE_ROOM.models, zone: "models" });
  if (input.talks) out.push({ room: ZONE_ROOM.talks, zone: "talks" });
  return out;
}

/**
 * Zone name anchors: on the road edge in front of each zone's first station, reading along the road
 * east (+x) or north (-z), so the floor text is upright for the default follow camera (south-east of
 * the rover). Zones without a station sit at `fallback`.
 */
export function signsFor(stations: readonly LibraryStation[], fallback: Vec2): LibraryLayout["signs"] {
  const inset = LIBRARY_FLOOR.road / 2 - 1.4;
  const out = {} as LibraryLayout["signs"];
  for (const zone of LIBRARY_ZONES) {
    const s = stations.find((st) => st.zone === zone);
    if (!s) {
      out[zone] = { at: fallback, heading: { x: 1, z: 0 } };
      continue;
    }
    const along = Math.abs(s.facing.z) > 0.5 ? { x: 1, z: 0 } : { x: 0, z: -1 };
    out[zone] = { at: { x: s.from.x + s.facing.x * inset, z: s.from.z + s.facing.z * inset }, heading: along };
  }
  return out;
}

/**
 * Paper plates of the Research station: spread along its front, 0.15 u outside the glass (so a click
 * reaches the plate, not the station) and turned toward the road (`yaw` as in `HoloIcon` faces).
 */
export function paperSlots(station: LibraryStation, count: number): (Vec2 & { yaw: number; width: number })[] {
  const along = { x: Math.abs(station.facing.z), z: Math.abs(station.facing.x) };
  const w = station.rect.maxX - station.rect.minX;
  const d = station.rect.maxZ - station.rect.minZ;
  const span = along.x * w + along.z * d;
  const front = Math.abs(station.facing.x) * (w / 2) + Math.abs(station.facing.z) * (d / 2) + 0.15;
  const step = (span - 1) / Math.max(1, count);
  const yaw = Math.atan2(-station.facing.x, -station.facing.z);
  return Array.from({ length: count }, (_, i) => {
    const t = -span / 2 + 0.5 + step * (i + 0.5);
    return { x: station.center.x + along.x * t - station.facing.x * front, z: station.center.z + along.z * t - station.facing.z * front, yaw, width: Math.min(1.8, step - 0.3) };
  });
}

/** Follow-camera yaw that looks at a station from its road (see `ViewZone.yaw` in camera/orbit.ts). */
export function stationYaw(facing: Vec2): number {
  if (facing.z < -0.5) return 0;
  if (facing.z > 0.5) return Math.PI / 2;
  if (facing.x < -0.5) return Math.PI / 4;
  return -Math.PI / 2;
}

/** A camera zone around every door pad that turns the follow camera toward its station. */
export function stationViewZones(stations: readonly LibraryStation[]): ViewZone[] {
  return stations.map((s) => {
    const r = 2.2;
    return { id: s.room, area: { minX: s.door.x - r, maxX: s.door.x + r, minZ: s.door.z - r, maxZ: s.door.z + r }, yaw: stationYaw(s.facing) };
  });
}

/** Pairs of docked posts that share at least one tag (each pair once, newer post first). */
export function tagLinks(input: LibraryLayoutInput): [RoomId, RoomId][] {
  const posts = input.posts.slice(0, LIBRARY_FLOOR.maxPosts);
  const out: [RoomId, RoomId][] = [];
  for (let i = 0; i < posts.length; i++)
    for (let j = i + 1; j < posts.length; j++) if (posts[i].tags.some((t) => posts[j].tags.includes(t))) out.push([roomOfPost(posts[i].slug), roomOfPost(posts[j].slug)]);
  return out;
}

const bare = ({ minX, maxX, minZ, maxZ }: Rect): Rect => ({ minX, maxX, minZ, maxZ });

/** Slab bounds around everything on the floor, with the shaft side fixed at `slabMinX`. */
export function floorBounds(rects: readonly Rect[], points: readonly Vec2[], pad: number): Rect {
  const xs = [...rects.flatMap((r) => [r.minX, r.maxX]), ...points.map((p) => p.x)];
  const zs = [...rects.flatMap((r) => [r.minZ, r.maxZ]), ...points.map((p) => p.z)];
  return {
    minX: LIBRARY_FLOOR.slabMinX,
    maxX: Math.max(...xs) + pad,
    minZ: Math.min(...zs) - pad,
    maxZ: Math.max(...zs) + pad,
  };
}

/** The `FloorLayout` every concept shares: doors from stations, obstacles, road, camera zones. */
export function libraryFloor(args: {
  bounds: Rect;
  stations: readonly LibraryStation[];
  extraObstacles: readonly Rect[];
  network: RoadNetwork;
  spawn: Vec2;
  viewZones?: ViewZone[];
}): FloorLayout {
  return {
    id: "L4",
    bounds: args.bounds,
    door: LIBRARY_FLOOR.door,
    approach: LIBRARY_FLOOR.approach,
    obstacles: [...args.stations.map((s) => bare(s.rect)), ...args.extraObstacles.map(bare)],
    spawn: args.spawn,
    arrival: args.spawn,
    accent: LIBRARY_FLOOR.accent,
    doors: args.stations.map((s) => ({ room: s.room, at: s.door, facing: s.facing })),
    road: args.network,
    viewZones: [...stationViewZones(args.stations), ...(args.viewZones ?? [])],
  };
}

/** Spurs for the stations (one per door, ending on its pad). */
export function stationSpurs(stations: readonly LibraryStation[], color: (zone: LibraryZone) => string) {
  return stations.map((s) => ({ room: s.room, from: s.from, to: s.door, width: DOCK.spurWidth, color: color(s.zone) }));
}

/** Zone colors (one hue per category, shared by spurs, icons and Page View markers if they ever need one). */
export const ZONE_TONE: Record<LibraryZone, string> = {
  blog: "#22d3ee",
  research: "#fbbf24",
  models: "#a78bfa",
  talks: "#f472b6",
};

import type { Plaza, Road, RoadNetwork } from "../../../nav/road";
import type { Rect, Vec2 } from "../../../types";
import {
  dockAlong,
  floorBounds,
  LIBRARY_FLOOR,
  libraryFloor,
  shelfItems,
  signsFor,
  splitPosts,
  stationSpurs,
  tagLinks,
  ZONE_TONE,
  type LibraryLayout,
  type LibraryLayoutInput,
  type LibraryStation,
} from "../model";

/**
 * Concept A, "Reading Room": a closed reading loop (no dead ends) around a round atrium where an open
 * book hologram floats and turns its pages. An aisle crosses the atrium from the lead road. Themed
 * alcoves line the loop: the Blog alcoves on the north side (outer and inner rows, newest first), the
 * Research alcove on the east side, Models and Talks on the south side. Pure.
 */
export const ATRIUM = {
  west: -6,
  north: -22,
  south: 18,
  size: 20,
  /** Distance from a loop corner to the first alcove on a side. */
  start: 10,
  /** Clear road from the last alcove to the next corner. */
  tail: 10,
  board: { w: 7, d: 0.6, z: 12 },
} as const;

export function buildAtriumLayout(input: LibraryLayoutInput): LibraryLayout {
  const A = ATRIUM;
  const { docked, archive } = splitPosts(input);
  const shelves = shelfItems(input);
  const research = shelves.filter((s) => s.zone === "research");
  const lower = shelves.filter((s) => s.zone !== "research");

  const nw: Vec2 = { x: A.west, z: A.north };
  const east = { x: A.west + 1, z: A.north };
  const outer = dockAlong(docked.filter((_, i) => i % 2 === 0), { a: nw, b: east, side: -1, start: A.start });
  const inner = dockAlong(docked.filter((_, i) => i % 2 === 1), { a: nw, b: east, side: 1, start: A.start });
  const southNeed = dockAlong(lower, { a: { x: 0, z: 0 }, b: { x: -1, z: 0 }, side: -1, start: A.start }).end;
  const E = A.west + Math.max(outer.end, inner.end, southNeed, A.size + 2 * A.start) + A.tail;
  const ne: Vec2 = { x: E, z: A.north };
  const se: Vec2 = { x: E, z: A.south };
  const sw: Vec2 = { x: A.west, z: A.south };

  const posts: LibraryStation[] = docked.map((_, i) => (i % 2 === 0 ? outer.stations[i / 2] : inner.stations[(i - 1) / 2]));
  const r = dockAlong(research, { a: ne, b: se, side: -1, start: A.start });
  const low = dockAlong(lower, { a: se, b: sw, side: -1, start: A.start });
  const stations = [...posts, ...r.stations, ...low.stations];

  const center: Vec2 = { x: (A.west + E) / 2, z: 0 };
  const loop: Road = { id: "loop", points: [nw, ne, se, sw], width: LIBRARY_FLOOR.road, closed: true };
  const lead: Road = { id: "lead", points: [LIBRARY_FLOOR.approach, { x: A.west, z: 0 }], width: LIBRARY_FLOOR.road };
  const aisle: Road = { id: "aisle", points: [{ x: A.west, z: 0 }, center, { x: E, z: 0 }], width: LIBRARY_FLOOR.road };
  const atrium: Plaza = { id: "atrium", center, w: A.size, d: A.size, round: true };
  const network: RoadNetwork = { roads: [lead, loop, aisle], plazas: [atrium], spurs: stationSpurs(stations, (z) => ZONE_TONE[z]) };

  // Archive board on the atrium's south rim, facing north; the stop is inside the atrium.
  const boardCenter = { x: center.x, z: A.board.z };
  const board = archive.length
    ? {
        rect: { minX: boardCenter.x - A.board.w / 2, maxX: boardCenter.x + A.board.w / 2, minZ: boardCenter.z - A.board.d / 2, maxZ: boardCenter.z + A.board.d / 2 },
        center: boardCenter,
        stop: { x: boardCenter.x, z: boardCenter.z - A.board.d / 2 - 3 },
      }
    : null;

  const extra: Rect[] = board ? [board.rect] : [];
  const corners = [nw, ne, se, sw].map((c) => ({ x: c.x, z: c.z }));
  const bounds = floorBounds([...stations.map((s) => s.rect), ...extra], corners, LIBRARY_FLOOR.margin + LIBRARY_FLOOR.road / 2);
  const spawn = { x: A.west + 3, z: 5 };
  const floor = libraryFloor({
    bounds,
    stations,
    extraObstacles: extra,
    network,
    spawn,
    // From the west entry, look east across the atrium, zoomed out so the book and the first alcoves fit.
    viewZones: [{ id: "L4:atrium", area: { minX: A.west - 4, maxX: A.west + 4, minZ: -4, maxZ: 8 }, yaw: (-3 * Math.PI) / 4, zoom: 1.3 }],
  });

  return {
    concept: "atrium",
    floor,
    network,
    stations,
    archive,
    board,
    signs: signsFor(stations, center),
    centerpiece: center,
    links: tagLinks(input),
    extras: {},
  };
}

import type { Plaza, Road, RoadNetwork } from "../../../nav/road";
import type { Rect, Vec2 } from "../../../types";
import {
  dockAlong,
  floorBounds,
  LIBRARY_FLOOR,
  libraryFloor,
  shelfItems,
  signsFor,
  splitPosts,
  stationSpurs,
  tagLinks,
  ZONE_TONE,
  type DockItem,
  type LibraryLayout,
  type LibraryLayoutInput,
  type LibraryStation,
} from "../model";

/**
 * Concept B, "Newsroom": a press plaza in front of the elevator with a giant headline wall (scrolling
 * ticker of post titles) on its north edge and the featured post (the newest hosted post) on a stage on
 * its south edge. One timeline lane runs east: the other posts newest first, alternating north and
 * south, with year marks on the road where the year changes, then the Research, Models and Talks desks,
 * and a turnaround plaza (archive board on its east rim). Pure.
 */
export const NEWSROOM = {
  plaza: { x: -2, z: 0, w: 24, d: 20 },
  wall: { x: -3, z: -15, w: 18, d: 1, h: 7 },
  /** Featured stage: docked on the south side from the plaza center. */
  featuredStart: 2,
  /** First timeline station on the north and south sides (distance from the plaza center). */
  northStart: 14,
  southStart: 16,
  tail: 10,
  endPlaza: 16,
  board: { w: 0.6, d: 7 },
} as const;

export function buildNewsroomLayout(input: LibraryLayoutInput): LibraryLayout {
  const N = NEWSROOM;
  const P: Vec2 = { x: N.plaza.x, z: N.plaza.z };
  const east = { x: P.x + 1, z: P.z };
  const { docked, archive } = splitPosts(input);
  const featuredIndex = input.posts.slice(0, docked.length).findIndex((p) => !p.external);
  const featured: DockItem[] = featuredIndex >= 0 ? [docked[featuredIndex]] : [];
  const timeline: DockItem[] = [...docked.filter((_, i) => i !== featuredIndex), ...shelfItems(input)];

  const stage = dockAlong(featured, { a: P, b: east, side: 1, start: N.featuredStart });
  const northItems = timeline.filter((_, i) => i % 2 === 0);
  const southItems = timeline.filter((_, i) => i % 2 === 1);
  const north = dockAlong(northItems, { a: P, b: east, side: -1, start: N.northStart });
  const south = dockAlong(southItems, { a: P, b: east, side: 1, start: N.southStart });
  const lane: LibraryStation[] = timeline.map((_, i) => (i % 2 === 0 ? north.stations[i / 2] : south.stations[(i - 1) / 2]));
  const stations = [...stage.stations, ...lane];

  const endX = P.x + Math.max(north.end, south.end, N.northStart) + N.tail;
  const end: Vec2 = { x: endX, z: P.z };
  const pressPlaza: Plaza = { id: "press", center: P, w: N.plaza.w, d: N.plaza.d };
  const endPlaza: Plaza = { id: "end", center: end, w: N.endPlaza, d: N.endPlaza, round: true };
  const roads: Road[] = [
    { id: "lead", points: [LIBRARY_FLOOR.approach, P], width: LIBRARY_FLOOR.road },
    { id: "timeline", points: [P, end], width: LIBRARY_FLOOR.road },
  ];
  const network: RoadNetwork = { roads, plazas: [pressPlaza, endPlaza], spurs: stationSpurs(stations, (z) => ZONE_TONE[z]) };

  const wall: Rect = { minX: N.wall.x - N.wall.w / 2, maxX: N.wall.x + N.wall.w / 2, minZ: N.wall.z - N.wall.d / 2, maxZ: N.wall.z + N.wall.d / 2 };
  const boardCenter = { x: end.x + N.endPlaza / 2 + 3 + N.board.w / 2, z: end.z };
  const board = archive.length
    ? {
        rect: { minX: boardCenter.x - N.board.w / 2, maxX: boardCenter.x + N.board.w / 2, minZ: boardCenter.z - N.board.d / 2, maxZ: boardCenter.z + N.board.d / 2 },
        center: boardCenter,
        stop: { x: boardCenter.x - N.board.w / 2 - 3, z: boardCenter.z },
      }
    : null;

  // Year marks on the lane: before the first post of each year (the featured post's year is on its stage).
  const years: { year: string; at: Vec2 }[] = [];
  let last = featuredIndex >= 0 ? input.posts[featuredIndex].date.slice(0, 4) : "";
  timeline.forEach((item, i) => {
    if (item.zone !== "blog") return;
    const year = input.posts.find((p) => `L4:${p.slug}` === item.room)!.date.slice(0, 4);
    if (year === last) return;
    last = year;
    // On the road edge in front of the first post of the year (alternating sides keep marks apart).
    years.push({ year, at: { x: lane[i].from.x, z: lane[i].from.z + lane[i].facing.z * (LIBRARY_FLOOR.road / 2 - 1.6) } });
  });

  const extra: Rect[] = [wall, ...(board ? [board.rect] : [])];
  const points = [
    { x: P.x - N.plaza.w / 2, z: P.z - N.plaza.d / 2 },
    { x: P.x + N.plaza.w / 2, z: P.z + N.plaza.d / 2 },
    { x: end.x + N.endPlaza / 2, z: end.z + N.endPlaza / 2 },
    { x: end.x - N.endPlaza / 2, z: end.z - N.endPlaza / 2 },
  ];
  const bounds = floorBounds([...stations.map((s) => s.rect), ...extra], points, LIBRARY_FLOOR.margin);
  const spawn = { x: P.x - 4, z: P.z + 3 };
  const floor = libraryFloor({
    bounds,
    stations,
    extraObstacles: extra,
    network,
    spawn,

import type { Plaza, Road, RoadNetwork } from "../../../nav/road";
import type { Rect, Vec2 } from "../../../types";
import {
  dockAlong,
  floorBounds,
  LIBRARY_FLOOR,
  libraryFloor,
  shelfItems,
  signsFor,
  splitPosts,
  stationSpurs,
  tagLinks,
  ZONE_TONE,
  type LibraryLayout,
  type LibraryLayoutInput,
  type LibraryStation,
  type LibraryZone,
} from "../model";

/**
 * Concept C, "Constellation": a round core plaza (a star core floats over it) with three spokes to
 * nebula plazas. Posts are stars docked along the east spoke (north and south rows, newest nearest the
 * core) and joined in the sky by lines to the posts they share a tag with. Research sits on the north
 * spoke, Models and Talks face each other on the south spoke, each zone under its own nebula. Pure.
 */
export const CONSTELLATION = {
  core: { x: 0, z: 0 } as Vec2,
  size: 24,
  /** First star on the east spoke (clear of the north and south spokes' stations by 6 u or more). */
  blogStart: 20,
  /** First station on the north and south spokes. */
  spokeStart: 16,
  tail: 8,
  nebula: 16,
  board: { w: 0.6, d: 7 },
} as const;

export function buildConstellationLayout(input: LibraryLayoutInput): LibraryLayout {
  const K = CONSTELLATION;
  const C = K.core;
  const { docked, archive } = splitPosts(input);
  const shelves = shelfItems(input);
  const toward = (dx: number, dz: number): Vec2 => ({ x: C.x + dx, z: C.z + dz });

  const northRow = dockAlong(docked.filter((_, i) => i % 2 === 0), { a: C, b: toward(1, 0), side: -1, start: K.blogStart });
  const southRow = dockAlong(docked.filter((_, i) => i % 2 === 1), { a: C, b: toward(1, 0), side: 1, start: K.blogStart });
  const posts: LibraryStation[] = docked.map((_, i) => (i % 2 === 0 ? northRow.stations[i / 2] : southRow.stations[(i - 1) / 2]));
  // Research on the east side of the north spoke; Models east and Talks west on the south spoke.
  const r = dockAlong(shelves.filter((s) => s.zone === "research"), { a: C, b: toward(0, -1), side: 1, start: K.spokeStart });
  const m = dockAlong(shelves.filter((s) => s.zone === "models"), { a: C, b: toward(0, 1), side: -1, start: K.spokeStart });
  const t = dockAlong(shelves.filter((s) => s.zone === "talks"), { a: C, b: toward(0, 1), side: 1, start: K.spokeStart });
  const stations = [...posts, ...r.stations, ...m.stations, ...t.stations];

  const blogEnd = toward(Math.max(northRow.end, southRow.end, K.blogStart) + K.tail, 0);
  const northEnd = toward(0, -(Math.max(r.end, K.spokeStart) + K.tail));
  const southEnd = toward(0, Math.max(m.end, t.end, K.spokeStart) + K.tail);
  const roads: Road[] = [
    { id: "lead", points: [LIBRARY_FLOOR.approach, C], width: LIBRARY_FLOOR.road },
    { id: "blog", points: [C, blogEnd], width: LIBRARY_FLOOR.road },
    { id: "research", points: [C, northEnd], width: LIBRARY_FLOOR.road },
    { id: "shelves", points: [C, southEnd], width: LIBRARY_FLOOR.road },
  ];
  const plazas: Plaza[] = [
    { id: "core", center: C, w: K.size, d: K.size, round: true },
    { id: "nebula-blog", center: blogEnd, w: K.nebula, d: K.nebula, round: true },
    { id: "nebula-research", center: northEnd, w: K.nebula, d: K.nebula, round: true },
    { id: "nebula-shelves", center: southEnd, w: K.nebula, d: K.nebula, round: true },
  ];
  const network: RoadNetwork = { roads, plazas, spurs: stationSpurs(stations, (z) => ZONE_TONE[z]) };

  // Archive board on the east rim of the blog nebula, facing west.
  const boardCenter = { x: blogEnd.x + K.nebula / 2 + 3 + K.board.w / 2, z: blogEnd.z };
  const board = archive.length
    ? {
        rect: { minX: boardCenter.x - K.board.w / 2, maxX: boardCenter.x + K.board.w / 2, minZ: boardCenter.z - K.board.d / 2, maxZ: boardCenter.z + K.board.d / 2 },
        center: boardCenter,
        stop: { x: boardCenter.x - K.board.w / 2 - 3, z: boardCenter.z },
      }
    : null;

  const nebulae: Record<LibraryZone, Vec2> = {
    blog: { x: (C.x + K.blogStart + blogEnd.x) / 2, z: C.z },
    research: northEnd,
    models: { x: C.x + 10, z: southEnd.z },
    talks: { x: C.x - 10, z: southEnd.z },
  };
  const extra: Rect[] = board ? [board.rect] : [];
  const points = plazas.flatMap((p) => [
    { x: p.center.x - p.w / 2, z: p.center.z - p.d / 2 },
    { x: p.center.x + p.w / 2, z: p.center.z + p.d / 2 },
  ]);
  const bounds = floorBounds([...stations.map((s) => s.rect), ...extra], points, LIBRARY_FLOOR.margin);
  const spawn = { x: C.x - 5, z: C.z + 5 };
  const floor = libraryFloor({
    bounds,
    stations,
    extraObstacles: extra,
    network,
    spawn,
    // On the core: look east along the star spoke, zoomed out so the first stars and their links fit.
    viewZones: [{ id: "L4:core", area: { minX: C.x - 7, maxX: C.x + 7, minZ: C.z - 7, maxZ: C.z + 7 }, yaw: (-3 * Math.PI) / 4, zoom: 1.35 }],
  });

  return {
    concept: "constellation",
    floor,
    network,
    stations,
    archive,
    board,
    signs: signsFor(stations, C),
    centerpiece: C,
    links: tagLinks(input),
    extras: { nebulae },
  };
}

export interface LibraryWalkLabels {
  /** Zone names from messages (`library.posts`, `library.research`, `library.publications`, `library.talks`). */
  zones: Record<LibraryZone, string>;
  onMedium: string;
  more: string;
  moreSub: string;
}

export const LIBRARY_FILTERS: readonly LibraryZone[] = LIBRARY_ZONES;

/**
 * L4 "Read my writing": every station in the layout's order (docked posts, then Research, Models and
 * Talks), then the archive board when older posts did not fit. Post titles come from the payload
 * (content), zone names from messages; filters list only zones that have a stop.
 */
export function libraryWalk(library: LibraryData, labels: LibraryWalkLabels, layout: Pick<LibraryLayout, "stations" | "board">): WalkDefinition {
  const posts = new Map(library.posts.map((p) => [`L4:${p.slug}`, p]));
  const stops: WalkStop[] = layout.stations.map((s) => {
    const post = posts.get(s.room);
    const badge = post ? [...post.languages].sort().map((l) => l.toUpperCase()).join("/") : "";
    const subtitle = post ? [post.date.slice(0, 4), post.url ? labels.onMedium : badge].join(" · ") : undefined;
    return { id: s.room, to: s.room, room: s.room, title: post?.title ?? labels.zones[s.zone], subtitle, group: labels.zones[s.zone], tags: [s.zone] };
  });
  if (layout.board) {
    stops.push({ id: "L4:archive", to: layout.board.stop, palette: "posts", title: labels.more, subtitle: labels.moreSub, group: labels.zones.blog, tags: ["blog"] });
  }
  const filters = LIBRARY_FILTERS.filter((zone) => stops.some((s) => s.tags?.includes(zone))).map((id) => ({ id, label: labels.zones[id] }));
  return { id: "writing", floor: "L4", stops, filters };
}

/**

/**
 * Geometry data for open-book holograms (Atrium concept): every book is three pages around a vertical
 * spine, a left and a right page held open and one page that turns. All books share one geometry, so
 * the whole floor's books cost one draw call. Pure (plain arrays): Vitest runs it in node.
 */

export interface BookInstance {
  x: number;
  y: number;
  z: number;
  /** Yaw the open book faces (forward is (sin, cos)). */
  face: number;
  /** Page height in world units (a page is 0.75 of it wide). */
  size: number;
  /** 0..1 offset of the page-turn cycle, so neighbouring books do not turn together. */
  phase: number;
}

/** Page angles held open (radians from the right side around the spine); -1 marks the turning page. */
export const PAGE_ANGLES = [0.18, Math.PI - 0.18, -1] as const;
export const PAGE_SEGMENTS = 6;

export interface BookBuffers {
  /** Page-local position: x 0..1 away from the spine, y -0.5..0.5. */
  positions: number[];
  centers: number[];
  faces: number[];
  sizes: number[];
  phases: number[];
  /** Fixed page angle, or -1 for the turning page. */
  angles: number[];
  indices: number[];
}

export function bookBuffers(books: readonly BookInstance[]): BookBuffers {
  const out: BookBuffers = { positions: [], centers: [], faces: [], sizes: [], phases: [], angles: [], indices: [] };
  for (const book of books) {
    for (const angle of PAGE_ANGLES) {
      const base = out.positions.length / 3;
      for (let i = 0; i <= PAGE_SEGMENTS; i++) {
        const u = i / PAGE_SEGMENTS;
        for (const v of [-0.5, 0.5]) {
          out.positions.push(u, v, 0);
          out.centers.push(book.x, book.y, book.z);
          out.faces.push(book.face);
          out.sizes.push(book.size);
          out.phases.push(book.phase);
          out.angles.push(angle);
        }
      }
      for (let i = 0; i < PAGE_SEGMENTS; i++) {
        const a = base + i * 2;
        out.indices.push(a, a + 1, a + 2, a + 1, a + 3, a + 2);
      }
    }
  }
  return out;
}

/**
 * Turning-page angle at time `t` (s) for a book with `phase`: rests on the right, turns over in the
 * middle of each 8 s cycle, rests on the left. Reduced motion holds it half open.
 */
export function turnAngle(t: number, phase: number, reducedMotion: boolean): number {
  if (reducedMotion) return Math.PI / 2;
  const cycle = (((t / 8 + phase) % 1) + 1) % 1;
  const k = Math.min(1, Math.max(0, (cycle - 0.3) / 0.4));
  return k * k * (3 - 2 * k) * Math.PI;
}

uniform float uTime; uniform float uMotion;
varying vec2 vUv;
void main(){
  vUv = vec2(position.x, position.y + .5);
  float cyc = fract(uTime/8. + aPhase);

  float turn = uMotion > .5 ? k*k*(3. - 2.*k)*3.14159 : 1.5708;
  float ang = aAngle < 0. ? turn : aAngle;
  ang += aAngle < 0. ? sin(position.x*3.14159)*.18*sin(turn) : 0.;
  vec3 p = vec3(cos(ang)*position.x*.75, position.y, sin(ang)*position.x*.75)*aSize;

  vec3 r = vec3(p.x*c + p.z*s, p.y, -p.x*s + p.z*c);
  gl_Position = projectionMatrix*modelViewMatrix*vec4(aCenter + r, 1.);
}`;

void main(){
  float edge = step(vUv.x, .04) + step(.96, vUv.x) + step(vUv.y, .03) + step(.97, vUv.y);
  float line = step(.55, fract(vUv.y*9.))*step(.18, vUv.x)*step(vUv.x, .86)*step(.12, vUv.y)*step(vUv.y, .82);
  float a = uOpacity*(.22 + .55*min(1., edge) + .25*line);
  gl_FragColor = vec4(uColor, a);
  #include <tonemapping_fragment>
  #include <colorspace_fragment>
}`;

/** Every open book on the floor in one geometry and one draw call (pages turn unless reduced motion). */
export function FlipBooks({ books, color, tier, reducedMotion }: { books: readonly BookInstance[]; color: string; tier: DecorProps["tier"]; reducedMotion: boolean }) {
  const full = tier === "full";
  const geometry = useMemo(() => {
    const b = bookBuffers(books);
    const g = new BufferGeometry();
    g.setAttribute("position", new Float32BufferAttribute(b.positions, 3));
    g.setAttribute("aCenter", new Float32BufferAttribute(b.centers, 3));
    g.setAttribute("aFace", new Float32BufferAttribute(b.faces, 1));
    g.setAttribute("aSize", new Float32BufferAttribute(b.sizes, 1));
    g.setAttribute("aPhase", new Float32BufferAttribute(b.phases, 1));
    g.setAttribute("aAngle", new Float32BufferAttribute(b.angles, 1));
    g.setIndex(b.indices);
    return g;
  }, [books]);
  const material = useMemo(
    () =>
      new ShaderMaterial({
        uniforms: { uTime: { value: 0 }, uMotion: { value: reducedMotion ? 0 : 1 }, uColor: { value: new Color(color).multiplyScalar(full ? 1.5 : 1) }, uOpacity: { value: full ? 0.9 : 0.75 } },
        vertexShader: VS,
        fragmentShader: FS,
        transparent: true,
        depthWrite: false,
        side: DoubleSide,
        blending: full ? AdditiveBlending : NormalBlending,
      }),
    [color, full, reducedMotion],
  );
  const list = useMemo(() => [material], [material]);
  useUniformTime(list);
  useEffect(
    () => () => {
      geometry.dispose();
      material.dispose();
    },
    [geometry, material],
  );
  return <mesh geometry={geometry} material={material} frustumCulled={false} raycast={() => null} />;
}

const TICKER = { speed: 2.4, separator: "   \u25c6   " } as const;

/**
 * Headline ticker: every post title in one troika text (written twice, so the loop has no seam),
 * scrolling left. The clip rect moves with the text, so only the part over the wall shows.
 */
function Ticker({ text, width, y, z, x, reducedMotion }: { text: string; width: number; y: number; z: number; x: number; reducedMotion: boolean }) {
  const ref = useRef<Mesh & { clipRect: [number, number, number, number] | null; textRenderInfo?: { blockBounds: number[] } | null }>(null);
  const offset = useRef(0);
  useFrame((_, dt) => {
    const t = ref.current;
    if (!t) return;
    const bounds = t.textRenderInfo?.blockBounds;
    const loop = bounds ? (bounds[2] - bounds[0]) / 2 : 0;
    if (!reducedMotion && loop > 0) offset.current = (offset.current + Math.min(dt, 0.1) * TICKER.speed) % loop;
    t.position.x = -offset.current;
    t.clipRect = [offset.current, -1, offset.current + width, 1];
  });
  return (
    <group position={[x - width / 2, y, z]}>
      <Text
        ref={ref}
        font={FONTS.monoBold}
        fontSize={0.62}
        anchorX="left"
        anchorY="middle"
        whiteSpace="nowrap"
        color={ZONE_TONE.blog}

function Nebulae({ centers, tier }: { centers: Partial<Record<LibraryZone, { x: number; z: number }>>; tier: DecorProps["tier"] }) {
  const full = tier === "full";
  const geometry = useMemo(() => {
    const pos: number[] = [];
    const uv: number[] = [];
    const tint: number[] = [];
    const idx: number[] = [];
    const color = new Color();
    for (const zone of LIBRARY_ZONES) {
      const c = centers[zone];
      if (!c) continue;
      const r = 9;
      const base = pos.length / 3;
      color.set(ZONE_TONE[zone]);

        pos.push(c.x + dx, 0.03, c.z + dz);
        uv.push(u, v);
        tint.push(color.r, color.g, color.b);
      }
      idx.push(base, base + 2, base + 1, base, base + 3, base + 2);
    }
    const g = new BufferGeometry();
    g.setAttribute("position", new Float32BufferAttribute(pos, 3));
    g.setAttribute("uv", new Float32BufferAttribute(uv, 2));
    g.setAttribute("aTint", new Float32BufferAttribute(tint, 3));
    g.setIndex(idx);
    return g;
  }, [centers]);
  const material = useMemo(
    () =>
      new ShaderMaterial({
        uniforms: { uOpacity: { value: full ? 0.16 : 0.12 } },

        fragmentShader: NEBULA_FS,

      material.dispose();
    },

  );

/** A star (small octahedron) over every post station, twinkling unless reduced motion (one instanced mesh). */
function Stars({ points, tier, reducedMotion }: { points: { x: number; z: number }[]; tier: DecorProps["tier"]; reducedMotion: boolean }) {
  const mesh = useRef<InstancedMesh>(null);
  const color = useMemo(() => neonColor(ZONE_TONE.blog, 1.8, tier), [tier]);
  const scratch = useMemo(() => ({ matrix: new Matrix4(), q: new Quaternion(), axis: new Vector3(0, 1, 0), at: new Vector3(), scale: new Vector3() }), []);
  useFrame(({ clock }) => {
    const m = mesh.current;
    if (!m) return;
    const { matrix, q, axis, at, scale } = scratch;
    points.forEach((p, i) => {
      const t = clock.elapsedTime;
      const s = reducedMotion ? 0.55 : 0.5 + 0.12 * Math.sin(t * 2.1 + i * 1.3);
      q.setFromAxisAngle(axis, reducedMotion ? 0 : t * 0.6 + i);
      matrix.compose(at.set(p.x, SKY, p.z), q, scale.set(s, s * 1.4, s));
      m.setMatrixAt(i, matrix);
    });
    m.instanceMatrix.needsUpdate = true;
  });
  if (!points.length) return null;
  return (
    <instancedMesh key={points.length} ref={mesh} args={[undefined, undefined, points.length]} frustumCulled={false} raycast={() => null}>
      <octahedronGeometry args={[1, 0]} />
      <meshBasicMaterial color={color} toneMapped={false} />
    </instancedMesh>
  );
}

      <icosahedronGeometry args={[2.6, 1]} />
      <meshBasicMaterial color={color} wireframe transparent opacity={0.6} toneMapped={false} />
    </mesh>
  );
}
