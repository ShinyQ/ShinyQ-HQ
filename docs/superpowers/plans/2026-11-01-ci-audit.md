# CI Audit Implementation Plan

Status: in review

Owner request: "I need you to audit our CI too since its takes so long can you maybe think which was really needed
to stay n which is needs to be removed since i think this was very2 long". Owner decision:
[2026-11-01](../../decisions/2026-11-01-ci-audit.md) (all of C1 to C7, plus G1 and G2).

**Goal:** Shorter PR waits with no gate removed: the average PR run from 16.1 min to about 11.5 min, full PR and
`main` runs from about 22 to 24 min to about 17 to 18 min, and no wait for a `main` run before the next PR push.

**Architecture:** The planner (`scripts/ci-plan.ts`) narrows what forces a full run and diffs the spec maps instead.
Every run stays within 10 e2e plus perf shards, the eight extra L1 perf poses run in the nightly (and on PRs that change
the Lobby or the office), Lighthouse splits into 2 shards behind one `Lighthouse CI` job, and the perf lane joins the
flaky report. Two nightly and process fixes go with it: the Screenshots nightly reports a red night, and a `main` run
may share the job cap with one selective PR run.

## Audit (2026-10-23 to 2026-10-31, 123 CI runs)

| Run type | Green runs | Median | p90 | Job that finished last |
|---|---|---|---|---|
| PR full (6 e2e + 4 perf shards) | 26 | 22.1 min | 26.5 | perf 22 of 26 |
| PR selective | 21 | 9.6 | 21.0 | Lighthouse 10 of 21 |
| `main`, full or near-full | 21 | 23.5 | 27.4 | perf 20 of 21 |
| `main`, small complement | 22 | 4.1 | 13.8 | unit tests |

- Setup is 39 s per Playwright job and queue time is zero: caches are not the problem.
- Full PR triggers: other workflows only (#319, #323, #352, #355, #359), the spec map (#312, #314, #316, #317, #320,
  #322), budgets with 3D code (#324, #327, #329, #346, #348, #362), dependencies (#309, #328, #344).
- Perf lane: 48 tests, 7,669 worker-seconds of measured medians; `memory-full` 798 s and the L1 full day replay 786 s
  are the long poles; the eight extra L1 poses are 2,742 s (36%).
- Flakes: the L1 full day replay made 7 jobs red (3 `main` runs) until #343; since then 11 perf retries (L1 lite day
  replay, `memory-full` at 11 to 13 min each), none in the flaky report.
- 12 of 22 long `main` runs were full because the PR was behind `main`; 15 of 52 deploys took the slow path (27.4 min).
- The Screenshots nightly was red 15 of 15 nights (`r5-p8 L3 review @ 390x844` times out at 18 min twice, 70 min shard).

## Tasks

- [x] C1: `CLASSES`: the `ci` class keeps `ci.yml`, `.github/actions/`, the dependency and config files, the e2e
  helpers and the CI scripts; other workflows fall to `docs`. New `planmap` class (`scripts/e2e-plan.ts`,
  `scripts/perf-plan.ts`): Plan CI loads the base versions (contents API at the PR base) and plans the specs and perf
  keys whose mapping differs over every tracked file (`mapDiff`); a failure plans a full run.
- [x] G1: ` @nightly` on the beacon, office in view, Agent Office and day replay poses of `e2e/perf/floors.spec.ts`
  (both tiers); the timeline tests use `@timeline`. The perf shards skip `@nightly` unless the run is the nightly or
  the PR changes the Lobby or the office (`perf_nightly`, `nightlyPerfFor`); the shard sizing counts the same tests.
- [x] C2: `HEAVY_SHARDS` (10) for every run: a full run is 6 e2e and 4 perf shards, a complement run fits the cap;
  `e2e/durations.json` refreshed from the latest nightlies.
- [x] C3: `Lighthouse shard n/N` matrix (2 shards from 4 URLs on a run with at most 8 e2e plus perf shards, `lighthouse_shards`) and a `Lighthouse CI` job that
  merges the shard reports, runs the complement merge, the main baseline and the per-chunk summary, uploads
  `lighthouse-reports` and fails unless every shard passed.
- [x] C4 (CI part): the perf shards upload `perf-blob-report-n`; the aggregate merges them to JSON and runs
  `scripts/flaky-report.ts --lane "3D perf"`.
- [x] C6 (reporting): `screenshots.yml` gets a `Nightly report` job; `scripts/ci-nightly.ts` takes `NIGHTLY_KIND`
  (`ci` or `screenshots`) for the label, title and wording.
- [x] C7: the `preview` job is gone.
- [x] C5 and G2: `AGENTS.md`, `docs/agents/ci-and-deploy.md`, `docs/agents/performance.md`.
- [ ] C4 (test fixes): the L1 lite day replay and `memory-full` perf flakes, in their own PR.
- [ ] C6 (test fix): the `r5-p8 L3 review @ 390x844` capture, in its own PR.
