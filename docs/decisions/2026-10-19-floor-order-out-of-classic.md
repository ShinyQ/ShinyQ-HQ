# Performance

- Date: 2026-10-19

Owner request (perf assessment item 3): "useHQStore imports @/experience/config, which pulls every floor layout into Classic (25.4 KB gz). Move FLOOR_IDS, floorIndex and the Lobby spawn to a tiny module. Owner decision: moving these bytes from Classic into the 3D path is fine if the 3D session caps still pass. Combine with item 7 to win the bytes back on 3D. Do not raise any budget without asking me." The floor order (`FLOOR_IDS`, `READY_FLOORS`, `floorIndex`) moved to `src/experience/floorOrder.ts` and the Lobby spawn with its kiosk axis to `src/experience/floors/lobby/spawn.ts` (both import only `@/lib/floors` and types; `config.ts` re-exports them, values unchanged); the store, the drawer host, the HUD and the locale switch read them, so no Classic page loads a floor layout, and `bun run build` fails when one does (`scripts/check-client-chunks.ts`). Classic `/en` scripts went from 239.5 to 218.9 KB gzip (13 to 12 scripts; `/en/labs` 234.7 to 214.2 KB). The 3D main path grows by the same layouts, 21.9 KB gzip on both tiers (full 440.9 to 462.8 KB, lite 417.3 to 439.2 KB), so this ships together with the 3D savings of item 7 that keep the caps; no budget changed.
