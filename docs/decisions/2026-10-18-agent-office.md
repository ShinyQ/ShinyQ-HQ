# L1 Agent Office

- Date: 2026-10-18

Owner request: "im thinking of making something like virtual office animation for the L1 where it shows my copilot or other agent working and it can show a little on what is it working (include idle, on progress, thinking) something like that (live, but if its not possible we can search other turn around), its show lot rover workin (or in sleep position if its not working)". Approved design ([spec](../superpowers/specs/2026-10-18-agent-office-design.md)): a mission-control office on the L1 south plaza strip (x about -6 to 13, z 12 to 21, slab not extended) with one curved row of five console desks and Rovers behind them facing visitors, plus a screen wall on the south edge holding the summary and the GitHub board, and a "+N" chip for sessions beyond five (owner pick "1" after a full-ring mock). Live from local agent hooks (GitHub Copilot, Claude Code, OpenAI Codex) through one privacy-filtering relay, plus semi-live public GitHub activity; free Cloudflare services only (a Worker with a SQLite Durable Object, Pages Functions). Privacy: the activity type always shows, the task title only for allowlisted public repositories, else "Client project"; code, prompts, file paths and client names never leave the machine. Nine states (working, thinking, reviewing, running tests, waiting on CI, needs Kurniadi, done, CI failed, asleep) with distinct faces, poses and screens. Visitors poll every 10 s while the office is in view (no WebSockets). Cloud agents appear through GitHub activity only.
